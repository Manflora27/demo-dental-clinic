# demo-dental-clinic

**Demo project — fictional business.** Brightwater Family Dental does not exist.

A sample small-business website for a fictional neighborhood dental clinic, built by Manel Terrible to show services, hours, contact details and an appointment-request form that work well on phones. All names, addresses and phone numbers are placeholders, and the form sends nothing.

Plain HTML, CSS and JavaScript, deployed on Vercel.
